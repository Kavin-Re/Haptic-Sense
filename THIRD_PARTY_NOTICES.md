## What this mix means in practice

- **The built firmware is a combined work, not an Apache-2.0 binary.** It links
  Apache-2.0 application code with T-Licensed kernel code and ST code under SLA0044 and
  SLA0103. Each part keeps its own terms.
- **SLA0044 has two conditions that matter for reuse.** The software may be used only on
  or with a microcontroller or microprocessor made by or for STMicroelectronics (clause 4),
  and it may not be used or redistributed in a way that would subject it to open-source
  terms — the licence names Apache, BSD, MIT and GPL as examples (clause 5). That is why
  the Apache-2.0 grant here is scoped per file and does not extend to those components.
- **T-License** permits redistribution of the µT-Kernel source under its own conditions,
  including marking modified files; read the PDF above before redistributing a modified
  kernel tree.
- If you reuse only this project's original files (anything with the Apache-2.0 SPDX
  header), Apache-2.0 alone applies to them.
